Projects

BBClassify

An open-source Python package that estimates how accurate and consistent test-based classifications are, such as pass/fail decisions in licensure and certification exams, using the beta-binomial model. It succeeds BB-CLASS, a widely used program with an error in its Livingston and Lewis procedure that went unnoticed for over 20 years. BBClassify fixes the error and reproduces BB-CLASS's published results everywhere the error doesn't affect them. Available as a Windows program and as a pip-installable package.

betafunctions

An R package on CRAN for two- and four-parameter Beta distributions and for estimating the accuracy and consistency of test-based classifications. It implements three approaches (Livingston and Lewis, Hanson and Brennan, and multinomial/compound multinomial) for two or more categories, with ROC analysis, model-fit tests and results for each examinee or each score. It also includes distribution functions, moments and method-of-moments fitting for Beta, Beta-Binomial and related distributions.

PBI Model Health

A Python tool that analyses Power BI projects (PBIP/PBIR) to find cleanup candidates in the semantic model. It builds a dependency graph from reports, TMDL, DAX, relationships and Power Query, then classifies each object as used, needs review, likely unused or internal. Results come as a summary report and an Excel audit, through a desktop app and a command-line tool.

View on GitHub

Data Equivalence Analyzer

A Python tool that verifies a data migration from Excel to BigQuery by checking that every row in the old table also exists in the new one, even when column names differ and the new table has extra columns. It suggests column mappings from name similarity and shared values, counts duplicate rows correctly, and reports the missing rows and which columns most often break a match. It comes with a BigQuery downloader that has no row limit and a simple desktop interface.

View on GitHub

Ward Operations Dashboard

An interactive dashboard that helps a hospital ward manager compare recorded staffing activity with admissions, discharges and discharge timing, with timelines, weekday and hourly profiles, and side-by-side comparisons. It's built on a reproducible Python cleaning workflow that keeps raw data untouched, validates every step and keeps an audit trail. An optional AI assistant interprets the charts using aggregate data only, never individual records.
